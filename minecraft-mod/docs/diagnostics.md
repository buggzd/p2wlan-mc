# Mod 启动诊断与日志

[安装指南](quickstart.md) · [技术参考](../README.md)

本页说明 Fabric / Minecraft 1.21.1 Mod 的本地启动诊断。日志用于定位故障，不代替 Windows 真机、网络或游戏连通性验收。

## 游戏内查看

1. 打开菜单按钮旁的 P2WLAN 像素图标。
2. 点击「诊断日志」。即使助手启动失败、尚未登录或登录按钮禁用，这个入口仍可使用。
3. 页面显示助手状态、稳定错误码、初始化阶段、失败操作、逻辑文件类别及系统错误码。没有证据的项目显示未知，不推测根因。
4. 点击「复制诊断」，将脱敏摘要粘贴给维护者；也可点击「打开日志目录」取得文件。

`INITIALIZATION_FAILED / PROFILE_IO` 表示本机私有配置初始化期间的文件操作失败，不是账号密码验证失败。诊断中的操作和数字系统错误码才用于进一步定位。不要通过删除账号配置、放宽 ACL 或关闭安全检查来试错。

Windows 目录错误区分 `DRIVE_ROOT`（本地盘符根目录）、`ANCESTOR`（普通祖先目录）和 `PROFILE_DIRECTORY`（私有配置目录）。目录层级从盘符根目录的 `0` 开始；这些标签不包含真实盘符或目录名。系统错误码只说明失败类别，不识别占用进程。

## 文件位置

日志位于 **该游戏实例的实际运行目录**：

```text
logs/p2wlan-mod/startup.log
logs/p2wlan-mod/startup.log.1
```

HMCL 的启动器目录不一定是游戏运行目录；使用版本隔离时应查对应实例目录。`startup.log` 是当前段，`.1` 是上一轮转段。每段最多 256 KiB，仅保留一个备份；`startup.lock` 是空的写入者锁，不需要提交。

日志独立于 `config/p2wlan-private/`，在私有配置无法读取或原生程序未启动时仍可记录 Java 的启动阶段与失败码。目录不可写、被占用或文件不安全时，页面会明确显示文件日志不可用；此时使用「复制诊断」，不要去修改私有配置权限。

## 记录与隐私边界

日志记录本次启动标识、时间、事件序号、系统／CPU 架构、Java 主版本与位数、已验证原生包的版本／源码提交／摘要、资源提取、子进程启动、IPC 握手、失败、退出及清理事件。原生文件 I/O 错误只附带固定操作标签、逻辑文件类别、数字系统错误码和可选目录层级，不记录真实目录名。

不会记录账号邮箱、密码、Control URL、token、密钥、完整配置、IPC 请求／回复、游戏载荷、原始 stderr 或异常文本。日志不会自动上传。复制内容不包含本机绝对路径。

内存保留最近 64 条、每条最多 1024 字符；磁盘写入队列最多 128 条，由一个随启动生命周期结束的后台线程处理。摘要标明内存淘汰和队列丢弃数量；磁盘失败保留固定原因码，仍可复制内存摘要。日志不是会话／房间／路径状态的权威来源，也不用于决定重试或连接行为。

## 反馈内容

发送「复制诊断」内容，或者 `startup.log` 与存在时的 `startup.log.1`，并附上 Minecraft／Loader 版本、使用的 JAR 或 ZIP 名称及最短复现步骤。

**不要提交 `config/p2wlan-private/`、账号密码、会话 token 或未检查的 HMCL／Minecraft 完整日志。** 若需要额外原始日志，应先检查和脱敏，再明确确认接收方。独立的启动日志不等于 Windows 故障已经修复；仍需维护者依据真实失败证据核对根因。
